# Upload dan Running File Python di ESP32

## Skema 

| MODUL | GPIO | PIN CODE | OUTPUT | KETERANGAN |
|:---|:--- |:---|:---|:---|
| LED | GPIO2 | 2 | HIGH | LED ON |

## Programming ESP32

```python
from machine import Pin
from time import sleep_ms

led = Pin(2, Pin.OUT)

while True:
    led.on()
    sleep_ms(1000)
    led.off()
    sleep_ms(1000)
```

## Jalankan File Python di ESP32
1. Simpan file python di atas dengan nama `led_kedip.py`.
2. Hubungkan ESP32 ke komputer menggunakan kabel USB.
3. Pastikan driver USB to UART sudah terinstall di komputer anda. Jika belum, silahkan download dan install driver dari [situs resmi Espressif](https://www.espressif.com/en/support/download/other-tools).
4. Install adafruit-ampy dengan perintah berikut di terminal atau command prompt:

```terminal
ampy --port COM7 run led_kedip.py
```

Cara simpan program  didalam borad ESP32, gunakan perintah berikut:
1. Simpan file python di atas dengan nama `main.py`.
2. Hubungkan ESP32 ke komputer menggunakan kabel USB.

```terminal
ampy --port COM7 put main.py
```

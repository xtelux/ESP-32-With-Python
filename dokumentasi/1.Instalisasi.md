# Instalasi ESP32 MicroPython

## Flashing Fireware MicroPython ke ESP32
1. Pastikan anda sudah menginstall Python di komputer anda. Jika belum, silahkan download dan install Python dari [situs resmi Python](https://www.python.org/downloads/).
2. Install esptool dengan perintah berikut di terminal atau command prompt:

```python 
pip install esptool
```

```python
esptool --port COM7 erase_flash

esptool --port COM7 write_flash --flash_size=detect -fm dio 0 ESP32_GENERIC-20260824-v1.29.0.bin

esptool --port COM7 --baud 115200 write_flash 0x1000 
```

Cek dengan serial minitor, jika berhasil maka akan muncul pesan seperti berikut:

```
COM7 buad rate 115200

MicroPython v1.29.0 on 2026-08-24; ESP32
Type "help()" for more information.
>>>
from machine import Pin
led = Pin(2, Pin.OUT)
led.value(1) # untuk menyalakan led
led.value(0) # untuk mematikan led

```

## Menghubungkan ESP32 ke komputer
1. Hubungkan ESP32 ke komputer menggunakan kabel USB.
2. Pastikan driver USB to UART sudah terinstall di komputer anda. Jika belum, silahkan download dan install driver dari [situs resmi Espressif](https://www.espressif.com/en/support/download/other-tools).
3. Install adafruit-ampy dengan perintah berikut di terminal atau command prompt:

adafruit-ampy adalah sebuah tool yang digunakan untuk mengupload file ke board ESP32 yang sudah terinstall MicroPython. Anda dapat menginstallnya dengan perintah berikut:

```python
pip install adafruit-ampy
```

penggunaan adafruit-ampy untuk mengupload file ke ESP32 adalah sebagai berikut:

```terminal
ampy --port COM7 ls
-------------------
/boot.py
```

untuk mengupload file ke ESP32, gunakan perintah berikut:

```terminal
ampy --port COM7 put <nama_file.py>
```

untuk mengambil file dari ESP32, gunakan perintah berikut:

```terminal
ampy --port COM7 get <nama_file.py>
```

untuk menghapus file dari ESP32, gunakan perintah berikut:

```terminal
ampy --port COM7 rm <nama_file.py>
```

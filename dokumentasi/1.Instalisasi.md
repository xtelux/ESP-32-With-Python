# BAB 1: Instalasi dan Konfigurasi Lingkungan MicroPython pada ESP32

---

## 1.1 Pendahuluan

MicroPython adalah implementasi ulang dari bahasa pemrograman Python 3 yang dioptimalkan secara khusus untuk berjalan di lingkungan mikrokontroler dengan keterbatasan memori dan daya komputasi. Kehadiran modul sistem pada cip (*System on Chip* / SoC) seperti ESP32 yang dipadukan dengan kemudahan sintaksis Python membuka efisiensi tinggi dalam siklus riset dan pengembangan purwarupa Internet of Things (IoT).

Bab ini menguraikan langkah demi langkah persiapan lingkungan kerja di komputer host, prosedur penghapusan dan pengunggahan *firmware* (*flashing*) ke chip ESP32, verifikasi konsol interaktif REPL, hingga pengelolaan berkas kode sumber menggunakan utilitas baris perintah.

---

## 1.2 Persiapan Perangkat dan Driver Antarmuka

Sebelum berinteraksi dengan memori ESP32, ada dua prasyarat utama yang wajib disiapkan pada komputer *host*: penerjemah bahasa Python dan pengendali (*driver*) komunikasi serial.

### 1.2.1 Koneksi Fisik dan Driver USB-to-UART
Modul ESP32 berkomunikasi dengan komputer melalui jembatan antarmuka USB ke UART (*Universal Asynchronous Receiver-Transmitter*), seperti silikon CP2102, CH340, atau FTDI.

1. Hubungkan modul ESP32 ke port USB komputer menggunakan kabel data (pastikan bukan sekadar kabel pengisi daya/daya saja).
2. Periksa apakah sistem mengenali *Virtual COM Port* perangkat. Pada sistem operasi Windows, status ini dapat diverifikasi melalui **Device Manager** pada kategori **Ports (COM & LPT)**. Pada Linux/macOS, port biasanya dikenali sebagai `/dev/ttyUSB*` atau `/dev/cu.usbserial-*`.
3. Apabila port serial tidak terdeteksi atau muncul tanda seru kuning, unduh dan pasang pengandar dari penyedia cip jembatan atau melalui repositori alat pendukung pada [Situs Resmi Espressif](https://www.espressif.com/en/support/download/other-tools).

### 1.2.2 Lingkungan Kerja Python
Pastikan interpreter Python (disarankan versi 3.8 ke atas) beserta manajer paket `pip` telah terinstal di komputer. Konfirmasi ketersediaan paket dapat diuji melalui terminal:

```bash
python --version
pip --version
```

Jika belum terpasang, unduh paket penginstal dari [Situs Resmi Python](https://www.python.org/downloads/) dan pastikan opsi **"Add Python to PATH"** dicentang saat instalasi berlangsung.

## 1.3 Instalasi Tool Flashing dan Pembersihan Flash Memory

Proses penulisan biner MicroPython ke memori ESP32 memanfaatkan utilitas baris perintah berbasis Python bernama `esptool`.

### 1.3.1 Pemasangan esptool
Buka Terminal atau Command Prompt, kemudian jalankan perintah:

```bash
pip install esptool
```

### 1.3.2 Menghapus Memori Flash (Erase Flash)
Sangat dianjurkan untuk menghapus seluruh partisi flash lama guna mencegah konflik konfigurasi tabel partisi dan data NVS (*Non-Volatile Storage*):

```bash
esptool --port COM7 erase_flash
```

> **Catatan Teknis:**
> Ganti parameter `COM7` sesuai nomor COM port yang terbaca di sistem Anda (misal: `COM3`, `COM4`, atau `/dev/ttyUSB0` pada Linux).

---

## 1.4 Flashing Firmware MicroPython

Setelah chip dikosongkan, tahap selanjutnya adalah mengunggah citra (*image*) biner MicroPython resmi yang dapat diperoleh dari repositori unduhan MicroPython (ekstensi `.bin`).

Jalankan perintah berikut untuk menulis berkas biner ke memori:

```bash
esptool --port COM7 --baud 115200 write_flash --flash_size=detect -fm dio 0x1000 ESP32_GENERIC-20260824-v1.29.0.bin
```

### Penjelasan Parameter:
* `--port COM7`: Menentukan port target komunikasi serial.
* `--baud 115200`: Laju transmisi data serial (*baud rate*). Untuk proses penulisan yang lebih cepat pada chip berkualitas baik, nilai ini dapat dinaikkan ke `460800` atau `921600`.
* `write_flash`: Sub-perintah untuk menyalin data biner ke dalam memori flash.
* `--flash_size=detect`: Meminta `esptool` membaca header SPI flash secara otomatis untuk menentukan kapasitas IC memori.
* `-fm dio`: Mode antarmuka SPI flash (*Dual I/O*), format yang kompatibel untuk hampir seluruh modul ESP32 reguler.
* `0x1000`: Alamat offset memori flash tempat *bootloader* dan MicroPython dimuat (khusus arsitektur ESP32 klasik offset standar dimulai dari `0x1000`).
* `ESP32_GENERIC-20260824-v1.29.0.bin`: Nama berkas biner yang hendak diunggah.

---

## 1.5 Verifikasi Menggunakan REPL (*Read-Eval-Print Loop*)

Setelah proses *flashing* selesai, lakukan pengujian awal via Serial Monitor (seperti PuTTY, minicom, atau terminal bawaan IDE seperti Thonny/VSCode) dengan parameter:
* **Baud Rate:** `115200`
* **Data bits:** 8, **Parity:** None, **Stop bits:** 1 (8-N-1)

Tekan tombol reset (*EN*) pada papan ESP32. Jika instalasi berjalan dengan sukses, terminal akan menyajikan *prompt* REPL interaktif:

```text
MicroPython v1.29.0 on 2026-08-24; ESP32 module with ESP32
Type "help()" for more information.
>>>
```

### Uji Coba Perangkat Keras Sederhana (GPIO Output)
Ketik baris kode berikut langsung di REPL untuk menguji kendali pin logika output (LED *onboard* biasanya terhubung ke GPIO 2):

```python
from machine import Pin

# Menyiapkan GPIO 2 sebagai pin keluaran (Digital Output)
led = Pin(2, Pin.OUT)

# Menyalakan LED
led.value(1)

# Mematikan LED
led.value(0)
```

## 1.6 Manajemen Berkas Menggunakan adafruit-ampy

Saat beralih dari pengujian interaktif ke tahap produksi atau script mandiri, Anda perlu menyimpan kode ke dalam sistem berkas (*filesystem*) lokal ESP32 agar dapat dieksekusi otomatis saat board dinyalakan. Alat utilitas `adafruit-ampy` memfasilitasi kebutuhan ini melalui terminal.

### 1.6.1 Pemasangan ampy
Jalankan perintah berikut di konsol komputer:

```bash
pip install adafruit-ampy
```

### 1.6.2 Operasi Berkas Dasar
Berikut perintah umum untuk mengelola berkas di papan mikrokontroler:

* **Melihat daftar berkas di dalam sistem ESP32:**
  ```bash
  ampy --port COM7 ls
  ```
  *Luaran default:*
  ```text
  /boot.py
  ```

* **Mengunggah berkas program ke ESP32:**
  ```bash
  ampy --port COM7 put main.py
  ```
  *(Catatan: ESP32 akan mengeksekusi `boot.py` terlebih dahulu saat booting, diikuti oleh `main.py`).*

* **Mengunduh atau membaca isi berkas dari ESP32:**
  ```bash
  ampy --port COM7 get boot.py
  ```

* **Menghapus berkas dari ESP32:**
  ```bash
  ampy --port COM7 rm main.py
  ```

---

## 1.7 Rangkuman

Pada bab ini, kita telah menyelesaikan tahapan fondasional:
1. Mempersiapkan komunikasi serial melalui instalasi driver dan Python.
2. Menggunakan `esptool` untuk mengosongkan partisi flash dan memuat biner MicroPython ke alamat `0x1000`.
3. Melakukan pengujian interaktif pada antarmuka REPL menggunakan modul internal `machine.Pin`.
4. Mengoperasikan tool `ampy` untuk manipulasi siklus hidup berkas kode di dalam sistem penyimpanan mikrokontroler.

Dengan lingkungan yang telah siap, pada bab berikutnya kita akan mempelajari dasar-dasar arsitektur GPIO, pembacaan sinyal sensor analog/digital, serta manajemen interupsi.
